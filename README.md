Hi everyone! This is my first project, and I’m excited to share it. The Robo Hand blends creativity, engineering, and persistence. Built with 3D-printed PETG parts, ESP32s, servos, and ESP-NOW, each button controls a finger. More than a device, it proves that patience and curiosity can bring ideas to life.
You can see the guide and 3d models here - https://makerworld.com/ru/models/2298640-robohand#profileId-2508626
